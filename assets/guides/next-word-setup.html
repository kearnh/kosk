Better next-word suggestions

kosk already completes the word you are typing. Guessing the next word after a space needs a table of common two-word pairs. That table is large, so it is not shipped with kosk. Build it once on this machine with the steps below.

1. Download the word-pair counts

Download Peter Norvig's count_2w.txt and save it as {{CONFIG_DIR}}\count_2w.txt. Each line is two words and how often they appear together.

2. Build the tables kosk loads

From the kosk folder, run:

cargo run --bin completion_build -- --unigrams data/completion/en/unigrams.tsv --bigrams {{CONFIG_DIR}}\count_2w.txt --out {{MODEL_DIR}}

--out is the folder kosk reads for next-word tables. The generated files (vocab.txt, unigrams.bin, bigrams.bin) stay on this machine.

3. Restart kosk

kosk picks the new tables up on launch. If you edited settings instead of restarting, saving the settings file reloads them too.

How to check it worked

Type a word and a space, for example going . You should see words that follow it, like to. If you still only see common words like the, the pair table did not load.

Optional: three-word pairs

For longer context, also download count_3w.txt and add --trigrams with its path to the command above. With your own text, --corpus FILE counts pairs from one sentence per line.
